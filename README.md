# Tratamento_ENEM_Original
Tratamento de imagem da segunda prova ENEM de 2012, caderno 5

## Requisitos
Python3
Pdf2image

## Ativando ambiente virtual
### Linux
```
python3 -m venv venv  
source venv/bin/activate  
```
### Windows
```
python -m venv venv
venv\Scripts\activate.ps1
```
## Instalando pdf2image
```
pip install pdf2image    
```
